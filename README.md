# Columbia Asia Hospital Healthcare Analytics

An end-to-end healthcare analytics project using SQL and Power BI to study patient visits, waiting times, doctor performance and department referrals for Columbia Asia Hospital.

![Main Dashboard](screenshots/DASHBOARD_1_NAME.png)

## Objective
To clean and analyse hospital data and build interactive dashboards that help hospital management understand patient flow, waiting times and department workload.

## Tools Used
- Power BI Desktop (dashboards, DAX measures)
- MySQL Workbench (data analysis)
- Microsoft Word and PowerPoint (documentation and presentation)

## Business Questions Answered
- Is the hospital data clean, with no missing values or inconsistencies?
- What is the average waiting time before patients receive care?
- Which departments get the most visits through referrals?
- Which age groups visit the hospital the most?
- How does revenue and patient count differ across doctors?
- How do patient visits change month over month?
